# Which application should I use?
## Key management
### Mac
[GPG Suite](https://gpgtools.org/) should be installed and you should use GPG Keychain for creating and managing keys

### Windows
Download and install [Kleopatra](https://www.gpg4win.org/) part of the gpg 4 windows application

### Linux
Install [Kleopatra](https://apps.kde.org/kleopatra/) using the relevant one of the following commands:
	- Ubuntu: `sudo apt install kleopatra`
	- Fedora: `sudo dnf install kleopatra`
	- Arch Linux: `sudo pacman -S kleopatra`
	
## Encrypt/Decryption/Signing
### Mac
Use your text editor of choice and the services context menu

### Windows
Use the notepad function of [Kleopatra](https://www.gpg4win.org/) 

### Linux
Use the notepad function of [Kleopatra](https://apps.kde.org/kleopatra/)
