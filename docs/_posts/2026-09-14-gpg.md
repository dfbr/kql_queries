## Key management

### Mac

Install [GPG Suite](https://gpgtools.org/) and use **GPG Keychain** to create and manage keys.

### Windows

Install [Gpg4win](https://www.gpg4win.org/), which includes **Kleopatra** for creating and managing keys.

### Linux

Install [Kleopatra](https://apps.kde.org/kleopatra/) with your distribution's package manager:

- Ubuntu: `sudo apt install kleopatra`
- Fedora: `sudo dnf install kleopatra`
- Arch Linux: `sudo pacman -S kleopatra`

## Encrypting, decrypting and signing

### Mac

Use any text editor together with the **Services** menu that GPG Suite adds. See [Encrypting messages and files with GPG on a Mac]({% post_url 2026-10-27-encrypting-files-with-gpg-on-a-mac %}).

### Windows and Linux

Use the **Notepad** feature in Kleopatra.
